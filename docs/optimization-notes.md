# v1.5.3 资源与稳定性优化

- 自动探测并检查 PowerShell 7 运行组件版本；启动失败显示原因。
- 状态和设置按文件修改时间、大小缓存；每 30 秒强制复读作为兜底。失败读取不记入缓存，倒计时与数据过期判断独立刷新。
- 任务列表按任务 ID 增量更新，保持托管排序、当前选中任务与滚动位置。
- 隐藏到托盘后界面每 5 秒更新；后台额度保护频率不受影响。
- 输出队列最多 120 条、界面日志最多 60 条，每条最多 4096 字符，按批更新。
- 每个日志目录保留当前文件及 3 个轮转文件，每个约 4 MiB。日志查看器最多加载最近 10000 条、显示 2000 条。
- 连续连接失败逐步延长重试间隔，通常最多 5 分钟；正常轮询间隔大于 5 分钟时不提前重试。成功后恢复正常频率，手动继续和刷新可立即重试。
- 释放旧后台进程对象与事件订阅；同一任务同一按钮的连续点击在 3 秒内合并。
- 身份或兼容校验导致后台停止时不自动反复拉起；手动重试仍须重新通过后台校验。

保留原有额度策略、人工暂停与恢复确认流程。未增加强制清内存、防休眠或自动购买额度。

构建和隔离策略检查已执行；没有对真实聊天进行暂停/恢复验收，没有测量具体内存降幅。本版通过 GitHub 发布页提供下载。
