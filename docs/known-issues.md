# 已知问题与待验证项

适用版本：v1.5.1。本页不包含真实账号、聊天、运行日志或本机路径。

## 本版已修复

| 问题 | 修复行为与验证 |
| --- | --- |
| 取消托管后仍可能暂停或继续 | 对所有任务阶段检查管理范围；取消时清除单次继续、强制暂停及恢复意图，并标记解除控制。正在确认中的任务也可取消登记。已验证原观察、已继续、暂停、排队及请求确认等状态。已经发送给客户端的请求无法撤回，但不会据旧记录继续发送控制请求。 |
| 双项模式缺失周额度仍允许恢复 | 所选任一额度未知时，自动恢复与手动继续均等待；单项模式不要求未选额度通过百分比检查。已验证两项缺失数据及手动、自动分支。 |
| 聊天内控制不能唤醒已停止的后台 | 已有窗口通过进程间唤醒信号启动后台；处于停止过程时保留请求，后台退出后再启动。兼容已有桥接的托盘启动入口。已验证独立进程发出唤醒信号及延后启动。 |
| 重启后未加载原聊天一直等待 | 符合继续条件的托管任务会自动打开原聊天，随后仍核实客户端归属、任务身份及额度。未确认时按间隔重试；取消托管、手动保持暂停、关闭自动恢复或额度不足时不自动打开。显式手动继续仍可触发加载。已通过隔离的加载、重试及禁止打开场景验证。 |

## 真实验收边界

当前已进行模拟额度、状态机、加载重试及跨进程唤醒检查，并曾验证真实任务的暂停、手动继续。新版完整跨越服务端额度重置后的无人干预自动续跑，以及真实客户端完全退出重启后的原聊天自动加载，仍需真实完整周期验收；模拟测试不能替代这两项验收。

本地轮询存在延迟，不能保证购买积分零消耗。客户端协议更新也可能影响控制兼容性。
